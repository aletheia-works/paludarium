# 制限

paludarium は、まだ若いプロジェクトです。次のことは、今はできないか、確かめていません。

## できないこと

- **動的リンクのプログラム**：静的にリンクしたプログラムだけを動かせます。
- **32-bit の x86、AVX、AVX-512、x87、MMX**：対象外です。
- **ネットワーク**：`socket()` はいつも `EAFNOSUPPORT` を返します。使えるのは、
  AF_UNIX の `socketpair`（`SOCK_STREAM`、`SOCK_SEQPACKET`、`SOCK_DGRAM`）だけです。
- **書き込める共有のファイルのマッピング**：`mmap` は、マッピングを作るときにファイルの
  中身を写し取ります。`MAP_PRIVATE` のマッピングは Linux と同じように動き、読むだけの
  `MAP_SHARED` も、ファイルが変わるまでは同じです（後の変更はマッピングに見えません）。
  `PROT_WRITE` を付けた `MAP_SHARED` は `ENODEV` を返し、`mprotect` でも共有のファイルの
  マッピングを書き込めるようにはできません（`EACCES`）。書いた中身をファイルへ戻す
  仕組みがないためです。ファイルの終わりより完全に先にあるページは、`MADV_DONTNEED`
  のあとも含めて、`SIGBUS` にならず 0 として読めます。
- **読み込み専用の ELF のセグメントへの `MADV_DONTNEED`**：プログラムの書き込める
  セグメントは Linux と同じく実行ファイルを読み直しますが、読み込み専用のもの（コード）は
  中身を残します。違いが出るのは、`mprotect` で書き込めるようにして書き換えたときだけで、
  Linux では実行ファイルから読み直します。
- **一部のシステムコール**：実装していないシステムコールは `ENOSYS` を返すので、
  プログラムによってはその機能なしで続けられます。`sendmsg` と `recvmsg` もその
  ひとつで、ソケットでディスクリプタを受け渡せません（`SCM_RIGHTS`）。`chown`、
  `fchown`、`lchown`、`fchownat` もそうで、すべてのファイルは root（ユーザーと
  グループが 0）のものです。
- **穴のあるファイル**：メモリ上のファイルシステムのファイルは穴を持てないので、
  `ftruncate` や `fallocate` で大きくすると、新しい大きさの分だけホストのメモリを
  使います。
- **シグナルの細部**：コアファイルは書かないので、`SIGSEGV` や `SIGABRT` など
  コアダンプするシグナルで終わった子は、`wait` の状態にコアのフラグを立てずに `CLD_KILLED` として
  報告します。Linux では `CLD_DUMPED` になることがあります。
- **ネイティブの JIT**：JIT があるのは WebAssembly 版だけです。ネイティブ版は
  インタプリタで動きます。
- **stable の Rust**：nightly の Rust が必要です。

## 確かめていないこと

- 確かめたのは、[対応している機能](./features) に挙げたプログラムと、命令ごとのテストです。
  ほかのプログラムが完全に同じように動くことは、まだ保証していません。
- ファジングは、決まった時間の中で問題が見つからなかったことを示すもので、どんな入力でも
  安全だという証明ではありません。
- 差分テストの基準を取った CPU は、記録してある一部の AMD と Intel の CPU です。
  まだ観測していない CPU のプロファイルでは、テストがわざと止まるようにしてあります。
- メモリの上限は、まだ設けていません。信頼できないプログラムは、ホストのメモリを
  使い切るおそれがあります。タスク（スレッドとプロセス）と開けるファイルの数は、
  埋め込む側が上限を指定しない限り無制限です（[コマンドライン](./cli)、[Rust](./rust)、
  [JavaScript](./javascript)）。
- Safari の自動テストは、ブラウザの起動を待つ間に時間切れになることがありました。
  対策を入れて、10 回続けて成功していますが、今後揺れないことの保証ではありません。

## 不具合を見つけたら

CPU のフォールトでゲストが終わったときは、シグナル、アドレス、命令のバイト列が
表示されます。`--report-enosys` を付けて動かし直すと、`ENOSYS` を返したシステムコールも
わかります（[コマンドライン](./cli#足りないものを探す)）。それらを添えて、
[Issue](https://github.com/aletheia-works/paludarium/issues) で知らせてください。
