# 比べないもの（命令ごとの差分テスト）

命令ごとの差分テストのゲスト（`tests/guests/insn/*.c`）は、レジスタ・フラグ・メモリの値を文字で出力し、ネイティブの x86-64 Linux とエミュレータで出力をバイト単位で比べます。
x86 で結果が未定義になるフラグや値は、ゲストが出力する前にマスクで外します。この表が、命令ごとの「比べないもの」の一覧です（team.md の Testing Posture）。

| 命令 | 比べないもの | 理由（Intel SDM の定義） | マスクの場所 |
|------|--------------|--------------------------|--------------|
| and・or・xor・test・lock or | AF | 論理演算の後の AF は未定義 | `F_LOGIC`（insn.h） |
| shl・shr・sar（数が 1 以外） | OF | OF は数が 1 のときだけ定義される | `shift_mask`（shift.c） |
| shl・shr・sar（数が 1 以上） | AF | 数が 0 でなければ AF は未定義 | `shift_mask`（shift.c） |
| shl・shr（数がオペランドの幅以上。8・16 bit のとき起こる） | CF | 数が幅以上のとき CF は未定義 | `shift_mask`（shift.c） |
| imul（2 オペランド・3 オペランド） | SF・ZF・AF・PF | imul の後は CF・OF だけが定義される | `F_MUL`（muldiv.c） |
| div | すべてのフラグ | div の後のフラグはすべて未定義 | muldiv.c（フラグを出力しない） |
| bt | OF・SF・AF・PF | bt は CF を設定し ZF を変えない。ほかは未定義 | bt.c（`F_CF \| F_ZF` だけを出力） |
| div（0 除算・商のあふれ） | 試さない | #DE は中核のエミュレータではシグナルの配送がないため、範囲外（命令の形とシグナルのテストで扱う） | muldiv.c で入力から除く |

次のものは、未定義ではありませんが、命令の単位の差分テストでは比べません。

| 対象 | 理由 |
|------|------|
| スタックのアドレス、ゲストのコードのアドレス | 実行ごと・環境ごとに変わる値（team.md の Testing Posture）。ゲストは、アドレスそのものではなく、配列の添字などの差（`rep movsq` の rdi・rsi の進み）を出力する |
| `lock` の付いた命令の原子性 | 中核のエミュレータは 1 スレッドなので、値とフラグだけを比べる。複数スレッドでの原子性はスレッドのテストで確かめる |
